# web-tools

Herramienta web personal para descargar video y audio desde distintas plataformas (YouTube, Instagram, TikTok, Twitter/X, etc.), pensada también como proyecto de estudio (React + Tailwind en el frontend, Python + FastAPI en el backend).

Ver [plan-webapp-descargas.md](plan-webapp-descargas.md) para las decisiones de arquitectura y [pasos-implementacion.md](pasos-implementacion.md) para el checklist de implementación.

## Desarrollo local

```bash
npm install
npm run dev
```

Esto levanta backend (FastAPI) y frontend (Vite) juntos. Ver `pasos-implementacion.md` para el setup inicial de cada uno.
